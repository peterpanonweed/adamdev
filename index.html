The shift

The bottleneck moved.
I moved with it.

Software development used to reward the fastest typist. Not anymore. The craft has migrated upstream — from writing code to architecting systems, from syntax to specifications, from execution to supervision.

"The question isn't can they write clean code. The question is: can they write a specification clean enough that an AI can't misinterpret it?"

— Axel Molist Cordina, CEO WeUC

That's exactly what I do. I identify what needs to be built, break it into agent-sized thinking, and ship working products — fast. Vibe coding isn't a shortcut. It's the new architecture.
